# Predator - Feature Suggestions Plan

## Project Overview
Predator is a desktop YouTube/Instagram downloader built with Go + Wails + vanilla JS, using yt-dlp under the hood.

## Suggested Features

### High Priority

1. **Batch URL Input**
   - Allow pasting multiple URLs (one per line) in the input field
   - Process all URLs in sequence, showing combined progress
   - Useful for queueing multiple downloads at once

2. **Download Queue Management UI**
   - Show all queued/downloading items in a dedicated tab
   - Allow reordering (drag-and-drop) of queue
   - Pause/resume individual downloads
   - Remove items from queue before starting

3. **Platform Support Expansion**
   - Add support for more platforms: Vimeo, TikTok, Twitter/X, SoundCloud
   - These are well-supported by yt-dlp with minimal changes

4. **Scheduled Downloads**
   - Option to schedule downloads for later (e.g., "download at 2 AM")
   - Useful for scheduling large downloads during off-peak hours

5. **Quality Presets**
   - Save custom quality presets (e.g., "1080p H.264", "320kbps MP3")
   - Quick-select from saved presets instead of manual selection

### Medium Priority

6. **Dark/Light Theme Toggle**
   - Currently only dark theme exists
   - Add light theme option in settings

7. **Download Speed Limiter**
   - Option to limit bandwidth usage (e.g., "max 5 MB/s")
   - Useful for users with limited bandwidth

8. **Automatic File Organization**
   - Option to organize downloads into subfolders by:
     - Platform (YouTube/, Instagram/)
     - Date (2024/, 2025/)
     - Playlist name
   - Custom naming templates

9. **Subtitle/Caption Download**
   - Add option to download subtitles alongside video
   - Support choosing subtitle language
   - Formats: SRT, VTT, ass

10. **Clipboard Monitoring**
    - Option to auto-detect URLs copied to clipboard
    - Show notification asking if user wants to download

### Lower Priority

11. **Download Statistics**
    - Total data downloaded
    - Most downloaded channels
    - Time spent downloading

12. **Command Line Mode**
    - Allow running from command line for power users
    - `predator --url "youtube.com/..." --format mp3 --output ./downloads`

13. **Portable Mode**
    - Option to run from USB drive without installation
    - Store settings alongside executable

14. **Notification Sound Settings**
    - Customizable sound when download completes
    - Option to disable sounds

15. **Integration with System**
    - Add "Download with Predator" to browser context menu
    - Handle `youtube://` or `yt://` URL schemes

### Additional Suggested Features

16. **URL Validation with Platform Detection**
    - Auto-detect platform from URL and show icon (YouTube/Instagram/TikTok/etc.)
    - Validate URL format before attempting fetch
    - Show error message if URL is unsupported

17. **Concurrent Download Limit Setting**
    - Allow user to change max concurrent downloads (currently hardcoded to 3)
    - Options: 1, 2, 3, 4, 5 parallel downloads

18. **Retry Configuration**
    - Configure number of auto-retries on failure (currently 3)
    - Configure retry delay between attempts

19. **Auto-cleanup Options**
    - Option to auto-delete failed downloads after N days
    - Option to auto-delete completed entries after N days
    - Separate settings for history cleanup

20. **Download Template Customization**
    - Customize filename pattern (currently: `%(title)s [%(id)s] (%(resolution)s).%(ext)s`)
    - Add preset templates and custom format support
    - Preview filename before downloading

21. **Error Log Viewer**
    - Show detailed error logs for troubleshooting
    - Option to export logs for support requests

22. **Update Checker**
    - Manual check for app updates (currently checks yt-dlp)
    - Show update notifications
    - Changelog display

23. **Minimum File Size Filter**
    - Skip downloads smaller than specified size
    - Useful for filtering low-quality shorts/clips

24. **Channel/Playlist Subscription Monitor**
    - Track subscribed channels/playlists
    - Check for new videos periodically
    - Download new content automatically

25. **Search History**
    - Autocomplete from past URL inputs
    - Search previous downloads by title/URL

## Implementation Complexity Notes
- Features 1-3: Medium complexity, mostly frontend + existing backend patterns
- Features 4-5: Low complexity, mostly settings storage changes
- Features 6-10: Medium complexity, may need new UI elements
- Features 11-15: Lower priority, can be tackled later

## Next Steps
User should decide which features to prioritize for implementation.
